# 파일 입출력 (File I/O)

## 1. 파일 입출력이란?

프로그램에서 파일을 생성하거나,
파일에 데이터를 저장하고 읽어오는 기능이다.

---

# 2. 파일 열기

파일 객체를 생성하고,
파일 경로와 사용 목적(모드)을 지정한다.

예시:

    파일 객체 = open("경로", "모드")

---

# 3. 파일 열기 모드

| 모드 | 설명 |
| :---: | --- |
| w | 기존 내용을 삭제하고 새로운 내용으로 덮어쓰기 |
| a | 기존 내용을 유지하고 내용 추가하기 |
| r | 파일의 내용을 읽기 (파일이 없으면 오류 발생) |

---

# 4. 파일 출력하기

파일에 내용을 작성할 때 `write()` 메서드를 사용한다.

예시:

    파일 객체.write("문자열")

---

# 5. 파일 입력하기

파일의 내용을 읽을 때 사용한다.

예시:

    파일 객체.readlines()

`readlines()`는 파일의 모든 줄을 읽어 리스트 형태로 반환한다.

---

# 6. 파일 닫기

파일 사용이 끝나면 `close()` 메서드를 사용하여 파일을 닫는다.

예시:

    파일 객체.close()

파일을 닫지 않으면 데이터 저장 문제가 발생하거나
불필요하게 파일이 계속 열려 있을 수 있다.
