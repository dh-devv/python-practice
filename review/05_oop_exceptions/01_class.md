# 01. 클래스(Class)와 객체(Object) 개념

## 1. 클래스(Class)란?
> **공통 요소가 모인 곳 (설계도 / 틀)**

### 💡 클래스의 2가지 핵심 특징

1. **문장의 '주어' 역할을 한다.**
   * **문장 예시:** *Monkey eats banana*
   * **코드 표현:** `Monkey.eat("바나나")`
     * `Monkey` ➔ **주어** (클래스 / 객체)
     * `.eat()` ➔ **동사** (메소드 / 기능)
     * `"바나나"` ➔ **목적어** (매개변수 / 데이터)

2. **데이터의 '타입(Type)'이다.**
   * 공통 요소가 있는 것들을 클래스에 **한 번만 선언**해 두고 재사용한다.
   * 내부 요소에 접근하기 위해서는 해당 클래스의 타입으로 선언되어야 한다.

---

## 2. 클래스 선언 구조

```python
class 클래스명:
    # 필드 (객체, 메소드 등)
    pass
```

---

## 3. 객체(Object)와 객체화

* **객체(Object):** 추상적인 개념인 클래스를 **실체화**한 것
  | 구분 | 클래스 (추상적 개념) | 객체 (실체화된 것) |
  | :--- | :--- | :--- |
  | **예시 1** | 자동차 | 엄마 차 |
  | **예시 2** | 도형 | 네모 |

* **객체화:** 추상적인 개념을 구체화시키는 작업

---

## 4. 생성자(Constructor)

> `클래스명()` 형태로 사용하며, 동작 방식은 메소드와 같다.  
> **⚠️ 단, 리턴(return)이 불가능하다.**

### ⚙️ 생성자의 2가지 핵심 역할
1. **메모리 할당:** 해당 필드를 메모리에 올려 사용할 수 있게 만든다.
2. **초기화:** 객체가 만들어질 때 필요한 기본값을 설정한다.
