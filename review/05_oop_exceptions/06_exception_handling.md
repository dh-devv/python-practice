# 예외 처리 (Exception Handling)

## 1. 에러와 예외

### 에러 (Error)

프로그램 실행 자체가 어려운 심각한 오류

예시:
- 문법 오류
- 메모리 부족
- 시스템 오류

---

### 예외 (Exception)

프로그램 실행 중 발생할 수 있는 처리 가능한 오류

예외 처리를 사용하면 프로그램이 종료되지 않고
오류 상황에 대응할 수 있다.

예시:
- 0으로 나누기
- 존재하지 않는 파일 접근
- 잘못된 데이터 입력

---

# 2. 예외 처리 구조

`try-except` 문을 사용하여 예외를 처리한다.

예시:

    try:
        # 오류가 발생할 수 있는 코드

    except 오류 이름 as 객체:
        # 오류 발생 시 실행할 코드

---

# 3. Exception 클래스

`Exception`은 모든 예외 클래스의 부모 클래스이다.

어떤 예외인지 구체적으로 지정하지 않고
모든 오류를 처리하고 싶을 때 최상위 부모 클래스인
`Exception`을 사용할 수 있다.

예시:

    try:
        number = int(input("숫자 입력 : "))

    except Exception as e:
        print("오류 발생 :", e)

`Exception`은 모든 예외의 부모 클래스이기 때문에
다양한 종류의 오류를 하나의 코드로 처리할 수 있다.
